Demo Simulator
==============

A small rigid/affine body dynamics simulator assembled from IPC Toolkit
components. It is not part of the library; it exists to test the components
and to show how they fit together. See the `demo README
<https://github.com/ipc-sim/ipc-toolkit/tree/main/demo>`__.
